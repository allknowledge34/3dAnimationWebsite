# 🎞 Animated Carousel Slider Website

## 📖 Description

A modern animated carousel slider website built using HTML, CSS, and JavaScript featuring blur effects, smooth transitions, and creative transform animations.

---

## 📱 About

This project demonstrates how to create an impressive animated slider using pure front-end technologies without any external libraries.

It combines CSS transforms and filter blur effects to deliver smooth motion transitions and depth-style UI animations.

Key focuses of this project:

• Modern UI animation techniques  
• Creative CSS filter effects  
• Smooth carousel transitions  
• Clean JavaScript logic  
• Performance optimized design  

---

## 🚀 Features

- Animated carousel slider  
- Blur transition effects  
- Smooth transform animations  
- Responsive design  
- Pure HTML, CSS & JavaScript  
- No external libraries used  

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
